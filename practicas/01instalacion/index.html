Objetivo

El objetivo de este documento es facilitar los pasos necesarios para disponer en nuestro ordenador del entorno de prácticas con todas las herramientas necesarias para realizar las actividades de la asignatura.

Para Soporte a la Decisión usaremos las herramientas:

  • Metabase: funciona en Windows, Ubuntu y macOS.

  • Power BI: solo funciona en Windows.

  • KNIME: funciona en Windows, Ubuntu y macOS.

Para Soporte a la Colaboración usaremos varias herramientas en la Web (necesitamos un navegador actualizado y conexión a Internet), solo necesitaremos instalar:

  • Git: funciona en Windows, Ubuntu y macOS.
